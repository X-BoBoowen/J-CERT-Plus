# Earlier research studies (separate experimental identities)

`v6/` preserves the research source, graph data, inputs and raw results selected from the original sixth-edition reproducibility archive. Its `SOURCE_MANIFEST.json` identifies the original archive hash and selected members. The old manuscript, template files, old publication figures and precompiled native executables are excluded from this browsable historical collection. The dependency file describes the historical package; all-in-one paper checks may require files outside this subset. Use the individual experiment scripts and source-specific instructions for numerical work. Historical direct/PCG paths may require SuiteSparse development libraries and local compilation of the supplied C bridge.

`bounded_scale/` preserves the corrected four-scale study with normalized opinion vectors, raw timings, verification records and original scripts. Use it rather than the older unbounded-input scale observations in `v6/` when discussing the bounded opinion model. The maximum graph had only 32 candidates in that study, not an all-nonedge catalog. Read the original protocol before running.

Both studies retain the original data and environment definitions; do not mix them with V2/V4 complete-service ratios.
